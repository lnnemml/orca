# Хімічні нотатки

Тут живуть навчальні нотатки з квантової хімії — українською. Це персональний підручник,
який росте разом із застосунком: кожен новий тип розрахунку → нова сторінка або доповнення.

## Правила ведення (для Claude Code)
- Одна сторінка = один концепт (`dft-functionals.md`, `basis-sets.md`, `scf.md`,
  `td-dft.md`, `frequencies-thermochemistry.md`, `solvation-models.md`...)
- Кожна сторінка: інтуїція → мінімальна математика → як це виглядає в ORCA input →
  як це читати в output → типові помилки.
- Пов'язувати з практикою: посилання на реальні розрахунки автора (job id / молекула),
  де концепт було вжито.
- Це нотатки для навчання, не енциклопедія: приклади > формальність.

## Черга тем (поповнюється)
- [ ] SCF: що саме ітерується і чому воно збігається
- [ ] Базисні набори: def2-родина, коли SVP/TZVP, що таке aux basis (def2/J)
- [ ] RI, RIJCOSX: які інтеграли наближаються і ціна цього
- [ ] Функціонали: драбина Якова, чому r2SCAN-3c як робочий кінь, D4-дисперсія
- [ ] Freq: гармонічне наближення, уявні частоти, термохімія з output
- [ ] CPCM/SMD: неявна сольватація
